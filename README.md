# Soan Biryani and Sheermal House

Website for Soan Biryani and Sheermal House, Central Jacob Lines, Karachi.
Open daily 11 AM to 1 AM · WhatsApp orders: 0336 3390065

Plain HTML, CSS and JavaScript. No build step, no server, free to host.

## What's inside

- `index.html` — the whole website (menu, WhatsApp order cart, hours, map)
- `images/` — dish illustrations (SVG)
- `LICENSE` — MIT open-source license

## Put it online with GitHub Pages (free)

1. Sign in at github.com and click **New repository**. Name it, for example, `soan-biryani`, set it to **Public**, and create it.
2. Click **uploading an existing file**, drag in `index.html`, `README.md`, `LICENSE` and the `images` folder, then click **Commit changes**.
3. Go to **Settings → Pages**. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
4. After a minute or two your site is live at `https://YOUR-USERNAME.github.io/soan-biryani/`.

## Common edits

All menu items and prices are in the `MENU` list near the bottom of `index.html`.
To change a price, edit the `price:` number and commit. The WhatsApp number is the `WA` line just above it.

To use real photos instead of illustrations, upload them to `images/` (for example `chicken-biryani.jpg`)
and change that item's `img` value and the `.svg` ending to `.jpg` in `index.html`.
